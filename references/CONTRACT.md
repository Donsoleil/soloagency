# The soloagency contract

Every skill in this pack obeys these four rules. They are the difference
between advice and work.

## 1. Evidence, not assertion
Each skill ends with an **Evidence** line naming what output proves it ran: a
number pulled from a live source, a file written, a page shipped, a screenshot.
If you cannot produce it, write `NOT VERIFIED` and say what would produce it.
A confident paragraph is not evidence.

## 2. Read before you recommend
If a connector, export, or file can answer a question, read it. Never ask the
founder to recall a number their own Stripe account knows. Where a skill names
a connector, try it before falling back to asking.

## 3. Name the reversibility
Before any recommendation that costs money or is hard to undo, say which it is:
reversible (ship it, watch it), or one-way (slow down, get a second read).
Pricing changes on existing customers and anything with a signature are one-way.

## 4. Route out, don't fake competence
These skills cover business. When the ask turns into code, interface, or
compliance filing, say so and name the specialist. A skill that pretends to
cover everything covers nothing.

## Not advice
Nothing in this pack is legal, tax, or financial advice. It is preparation for
a conversation with someone licensed.
